kev-rust

Kev-0.8B in pure Rust on Candle. CPU or CUDA, fp32, no Python at runtime.

Benchmark explorer

Tesla T4, CUDA 13, fp32, warmed median, Google Colab. Small sample; see BENCHMARK.md in the repository. Rust is not faster than PyTorch at warmed GPU compute. Prefix batching is the main gain.

Request builder


  
target/release/kev-rust --input request.jsonl

  
Builds the input line for the CLI. Inference itself needs the exported weights and runs locally.
